# سَكَن — Sakan Real Estate Finder

A responsive real-estate discovery interface built with HTML, CSS and vanilla JavaScript.

## Interactive features
- Filter sample properties by area, type and maximum price.
- Sort by price or property size.
- Open a property details dialog.
- Save and remove favorites (persisted in localStorage).
- Compare up to three properties in a comparison table.
- Switch the layout direction between Arabic RTL and English LTR.
- Responsive property cards and search controls.

## Run
Open `index.html` in a browser or publish this folder with GitHub Pages.

## Important
This is a front-end portfolio demo. All property listings, prices and descriptions are fictional sample data. There is no backend, live property feed, account system or real-estate transaction service.
