# Daar E-commerce Store

واجهة متجر إلكتروني عربية متجاوبة، مناسبة كعرض أولي لمتجر صغير.

## المزايا
- عرض المنتجات حسب القسم
- البحث والفلترة
- سلة مشتريات متعددة العناصر
- حفظ السلة محلياً باستخدام localStorage
- تصميم متجاوب للهواتف والشاشات الكبيرة

## التشغيل
افتح `index.html` مباشرة في المتصفح أو شغّل `npx serve .`.

## ملاحظات النشر
هذه نسخة Frontend تجريبية. الدفع الفعلي، إدارة المخزون، حسابات العملاء والطلبات تحتاج Backend وقاعدة بيانات وبوابة دفع قبل استخدامها تجارياً.

## التقنيات
HTML, CSS, JavaScript, localStorage
