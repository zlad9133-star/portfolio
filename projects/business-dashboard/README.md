# Miyar Business Dashboard

لوحة تحكم عربية متجاوبة لإدارة مؤشرات نشاط تجاري صغير.

## المزايا
- مؤشرات المبيعات والطلبات والعملاء
- رسم بياني مبسط للمبيعات الأسبوعية
- توزيع مصادر الطلبات
- جدول طلبات مع البحث
- إضافة طلب جديد وتحديث البيانات
- حفظ الطلبات المضافة محلياً باستخدام localStorage

## التشغيل
افتح `index.html` مباشرة أو شغّل `npx serve .`.

## البيانات
البيانات المعروضة تجريبية لأغراض العرض فقط. لا تمثل شركة أو عملاء حقيقيين.

## التطوير للإنتاج
يتطلب الاستخدام الفعلي Backend موثوقاً، مصادقة وصلاحيات، قاعدة بيانات، تحققاً من المدخلات، وسجلات تدقيق.

## التقنيات
HTML, CSS, JavaScript, localStorage
