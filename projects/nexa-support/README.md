# Nexa — Customer Support Workspace

An interactive, responsive customer-support inbox built with HTML, CSS and vanilla JavaScript.

## Demo features
- Search conversations and filter by status.
- Switch between conversations and read message history.
- Send mock replies, close/reopen and snooze conversations.
- Create new conversations with a form.
- View customer and conversation details.
- Draft a sample reply, insert a quick reply and attach a local file name.
- Persist demo changes with localStorage.

## Run
Open `index.html` in a browser or publish this folder with GitHub Pages.

## Important
This is a front-end portfolio demo. Conversations and customer profiles are fictional sample data. Replies, AI drafting and attachments are simulated locally; there is no backend, real email delivery, live AI service or file upload server.
